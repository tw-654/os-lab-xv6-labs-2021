# 实验七：文件系统模拟实现

## 📚 实验简介

本实验实现了一个简化的单层目录文件系统，基于xv6文件系统设计思想。通过内存模拟磁盘空间，实现文件的创建、读写、删除等基本操作。

## 🎯 实验目标

### 已完成的功能

- ✅ **任务1**：空闲块查找函数 `find_free_blocks()`
- ✅ **任务2**：文件创建函数 `my_create()`
- ✅ **任务3**：文件写入函数 `my_write()`
- ✅ **任务4**：文件读取函数 `my_read()`
- ✅ **扩展1**：文件删除函数 `my_delete()`
- ✅ **扩展2**：磁盘状态显示函数 `show_disk_status()`
- ✅ **额外功能**：文件列表显示函数 `list_files()`

## 🔧 系统架构

### 核心数据结构

1. **文件控制块 (FCB)**
   - 文件名（最大20字符）
   - 文件大小（字节）
   - 起始块号
   - 有效标志

2. **文件系统管理器**
   - FCB表（最多32个文件）
   - 模拟磁盘（1MB内存数组）
   - 位示图（2048个块）

## 📝 功能说明

### 1. 空闲块查找 (find_free_blocks)

**功能**：在位示图中查找连续的空闲块。

**算法**：
- 遍历所有可能的起始位置
- 检查从起始位置开始的连续块是否都空闲
- 找到则返回起始块号，否则返回-1

**时间复杂度**：O(n²)，其中n为总块数

### 2. 文件创建 (my_create)

**功能**：创建指定大小的文件。

**步骤**：
1. 检查文件名是否已存在
2. 查找空闲的FCB
3. 计算需要的块数（向上取整）
4. 调用find_free_blocks分配空间
5. 标记块为已使用
6. 初始化FCB

**错误处理**：
- 文件名为空
- 文件已存在
- FCB表已满
- 磁盘空间不足

### 3. 文件写入 (my_write)

**功能**：向文件写入数据。

**步骤**：
1. 验证文件描述符
2. 计算磁盘起始地址
3. 使用memcpy写入数据
4. 处理长度限制

### 4. 文件读取 (my_read)

**功能**：从文件读取数据。

**步骤**：
1. 验证文件描述符
2. 计算磁盘起始地址
3. 使用memcpy读取数据
4. 添加字符串结束符

### 5. 文件删除 (my_delete)

**功能**：删除文件并释放空间。

**步骤**：
1. 验证文件描述符
2. 计算占用的块数
3. 在位示图中标记块为空闲
4. 清空磁盘数据（可选）
5. 标记FCB为无效

### 6. 磁盘状态显示 (show_disk_status)

**功能**：显示磁盘使用情况统计。

**显示信息**：
- 总块数、已用块数、空闲块数
- 总空间、已用空间、空闲空间（KB）
- 文件数量统计
- 空间使用率

## 🔍 技术要点

### 1. 连续分配策略

本实验采用**连续分配**方式：
- **优点**：实现简单，访问速度快
- **缺点**：可能产生外部碎片
- **适用场景**：文件大小已知且固定

### 2. 位示图空间管理

使用整型数组作为位示图：
- 0 表示空闲
- 1 表示占用
- 简化实现，易于理解

### 3. 内存模拟磁盘

使用字节数组模拟磁盘：
- 直接内存访问
- 无需真实I/O操作
- 便于测试和调试

### 4. FCB表固定大小

使用固定大小的FCB数组：
- 简化内存管理
- 限制最大文件数
- 适合教学演示

## ⚠️ 注意事项

1. **文件大小限制**：每个文件最大不超过磁盘大小（1MB）
2. **文件数量限制**：最多32个文件
3. **文件名限制**：最多19个字符（+1个'\0'）
4. **无目录支持**：单层目录，所有文件在根目录
5. **无权限管理**：未实现文件权限控制
6. **内存实现**：重启后数据丢失

### 常见错误排查

1. **段错误**：检查数组越界、空指针
2. **数据不一致**：检查memcpy的起始地址和长度
3. **空间分配失败**：检查位示图更新逻辑
4. **文件创建失败**：检查块数计算是否正确
