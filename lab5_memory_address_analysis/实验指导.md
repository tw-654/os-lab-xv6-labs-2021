
**分析要点：**

#### add() 函数的分析

```assembly
<add>:
    push   %rbp              # 保存前一个栈帧的帧指针
    mov    %rsp,%rbp         # 设置当前栈帧指针
    mov    %edi,-0x14(%rbp)  # 参数 a 存储到栈 [rbp-0x14]
    mov    %esi,-0x10(%rbp)  # 参数 b 存储到栈 [rbp-0x10]
    mov    -0x14(%rbp),%edx  # 从栈加载 a 到 edx
    mov    -0x10(%rbp),%eax  # 从栈加载 b 到 eax
    add    %edx,%eax         # 计算 a + b，结果在 eax
    mov    %eax,-0x4(%rbp)   # 结果存储到局部变量 result [rbp-0x4]
    mov    -0x4(%rbp),%eax   # 返回值通过 eax 寄存器传递
    pop    %rbp              # 恢复前一个栈帧指针
    ret                       # 返回
```

**要点：**
- 参数通过寄存器传递（edi = a, esi = b）
- 参数被复制到栈上的局部空间
- 返回值通过 eax 寄存器传递
- 局部变量 result 存储在栈上

#### increment_point() 函数的分析

```assembly
<increment_point>:
    push   %rbp
    mov    %rsp,%rbp
    mov    %rdi,-0x8(%rbp)   # 参数 p (指针) 存储在栈 [rbp-0x8]
    cmpq   $0x0,-0x8(%rbp)   # 检查 p 是否为 NULL
    je     <error_handler>   # 如果是 NULL，跳转到错误处理
    mov    -0x8(%rbp),%rax   # 加载指针 p 到 rax
    mov    (%rax),%eax       # 通过指针访问 p->x，加载到 eax
    lea    0x1(%rax),%edx    # 计算 x + 1
    mov    -0x8(%rbp),%rax   # 重新加载指针
    mov    %edx,(%rax)       # 写回 p->x = x + 1
    mov    -0x8(%rbp),%rax   # 加载指针
    mov    0x4(%rax),%eax    # 访问 p->y
    lea    0x1(%rax),%edx    # 计算 y + 1
    mov    -0x8(%rbp),%rax   # 重新加载指针
    mov    %edx,0x4(%rax)    # 写回 p->y = y + 1
    pop    %rbp
    ret
```

**要点：**
- 指针参数通过 rdi 寄存器传递
- 通过指针间接访问和修改堆内存中的数据
- 没有返回值（void 函数）

## 实验分析要点

### 1. 内存地址分布规律

观察运行结果，你会发现：

- **代码区地址**（函数地址）：通常是最小的，如 `0x400000` 附近
- **数据区地址**（全局变量）：接近代码区，如 `0x600000` 附近
- **堆区地址**（malloc 分配）：在数据区之后，如 `0x602000` 附近
- **栈区地址**（局部变量）：最大，接近高地址，如 `0x7fff...` 

### 2. 函数调用机制

#### 参数传递

在 x86-64 系统上：
- 前 6 个整数/指针参数通过寄存器传递：rdi, rsi, rdx, rcx, r8, r9
- 额外的参数通过栈传递
- 浮点参数通过 xmm 寄存器传递

#### 返回值传递

- 整数和指针返回值通过 rax 寄存器
- 大结构体可能通过指针返回

#### 栈帧结构

```
高地址
  [前一个函数的栈帧]
    ↓
  [保存的 rbp (帧指针)]    ← rbp 指向这里
  [返回地址]
  [保存的寄存器]
  [参数（如果通过栈传递）]
  [局部变量]
    ↓
  [当前栈顶]              ← rsp 指向这里
低地址
```

### 3. 堆内存管理

- `malloc()` 从堆中分配内存
- 堆内存地址在数据段之后
- 堆向上增长（向高地址）
- `free()` 释放内存，但不会立即归还给操作系统

### 4. 栈内存管理

- 局部变量自动分配在栈上
- 栈向下增长（向低地址）
- 函数返回时，栈帧自动释放
- 栈的大小有限（通常 8MB）

## 常见问题

### Q1: 地址每次运行都不同？

**A:** 这可能是由于地址空间布局随机化（ASLR）。可以通过以下方式禁用：

```bash
setarch $(uname -m) -R ./func_demo
```

或在编译时指定：

```bash
gcc -no-pie -fno-pie func_demo.c
```

### Q2: 如何查看更详细的栈帧信息？

**A:** 使用 GDB：

```gdb
(gdb) info frame        # 当前栈帧信息
(gdb) info locals      # 局部变量
(gdb) info args        # 参数
(gdb) info registers   # 所有寄存器
(gdb) x/10x $rsp       # 查看栈内容
```

### Q3: 如何理解汇编代码中的寻址方式？

**A:** 常见寻址方式：
- `(%rax)`：间接寻址，使用 rax 中的地址
- `0x4(%rax)`：基址+偏移，rax + 4
- `(%rax,%rbx)`：基址+变址，rax + rbx
- `0x4(%rax,%rbx,2)`：基址+变址*比例+偏移，rax + rbx*2 + 4
