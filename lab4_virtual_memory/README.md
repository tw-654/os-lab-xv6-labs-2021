# 实验四：虚拟存储器综合模拟

## 实验目的

综合运用前三个实验的技术，构建完整的虚拟存储系统，实现逻辑地址到物理地址的转换，处理缺页中断和页面置换。

## 系统架构

```c
typedef struct {
    pte_t page_table[256];          // 页表（256个条目）
    char physical_memory[4][4096];   // 物理内存（4帧，每帧4KB）
    char disk_storage[256][4096];    // 磁盘存储（256页，每页4KB）
    int page_faults;                 // 缺页统计
    int disk_io_count;               // 磁盘 I/O 统计
    int current_time;                // 当前时间戳（用于LRU）
    int frame_page_map[4];           // 帧到页的映射
} virtual_memory_system_t;
```

## 实现功能

### 任务 5.3.1：完整地址转换 (`vm_translate`)

实现完整的地址转换流程：

1. **计算页号和偏移量**
   - 逻辑地址除以页面大小得到页号
   - 逻辑地址模页面大小得到偏移量

2. **检查页表有效性**
   - 验证页号是否在有效范围内
   - 检查页表项的有效位

3. **处理缺页中断**
   - 当页面不在物理内存时触发缺页中断
   - 调用缺页处理函数加载页面

4. **返回物理地址**
   - 物理地址 = 帧号 × 页面大小 + 偏移量

### 任务 5.3.2：LRU 置换算法 (`lru_replace`)

实现 LRU (Least Recently Used) 页面置换算法：

1. **维护页面访问时间**
   - 每次页面访问更新最后访问时间
   - 使用时间戳记录访问顺序

2. **选择最久未使用的页面**
   - 遍历所有物理帧
   - 找到最后访问时间最早的页面

3. **处理页面写回**
   - 检查修改位（脏位）
   - 如果页面被修改，写回磁盘

4. **返回被置换的帧号**

## 关键概念

### 虚拟内存

虚拟内存系统允许程序使用比物理内存更大的地址空间。通过分页机制，将虚拟地址映射到物理地址。

### 页表

页表存储每个虚拟页到物理帧的映射关系，包括：
- 有效位：页面是否在物理内存中
- 修改位：页面是否被修改过
- 引用位：页面是否被访问过
- 帧号：对应的物理帧号

### 缺页中断

当程序访问的页面不在物理内存中时，触发缺页中断，需要：
1. 选择一个物理帧（如果有空闲）或置换一个页面
2. 从磁盘加载需要的页面
3. 更新页表

### LRU 置换算法

LRU (Least Recently Used) 是一种常用的页面置换算法，选择最久未使用的页面进行置换。它基于局部性原理：最近使用的页面更可能在未来被使用。

## 性能指标

- **缺页率**：缺页次数 / 总访问次数 × 100%
- **磁盘 I/O 次数**：页面加载和写回磁盘的次数
- **平均 I/O 次数/缺页**：反映置换算法的效率
