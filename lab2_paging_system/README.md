# 实验二：分页系统地址转换

## 实验概述

本实验实现了一个完整的分页系统模拟器，包括：
- **地址转换**：逻辑地址到物理地址的转换
- **缺页处理**：处理页面不在内存中的情况
- **FIFO页面置换算法**：当物理内存满时选择最早进入的页面置换
- **页表管理**：维护页表和物理帧信息

## 系统参数

- **最大页面数**：256页
- **物理帧数**：4帧
- **页面大小**：4096字节（4KB）
- **物理内存大小**：16KB（4帧 × 4KB）

## 数据结构

### 页表项 (Page Table Entry)
```c
typedef struct page_table_entry {
    int frame_num;          // 物理帧号
    bool valid;             // 有效位（是否在物理内存中）
    bool modified;          // 修改位（脏位）
    bool referenced;        // 访问位（引用位）
    int load_time;          // 页面加载时间（用于FIFO）
} pte_t;
```

### 分页系统管理器
```c
typedef struct {
    pte_t page_table[MAX_PAGES];         // 页表
    frame_info_t frames[MAX_FRAMES];     // 物理帧信息
    char physical_memory[MAX_FRAMES][PAGE_SIZE]; // 物理内存
    int page_fault_count;                // 缺页次数统计
    int memory_access_count;             // 内存访问次数统计
    int current_time;                    // 当前时间戳
} paging_system_t;
```

## 核心功能实现

### 1. 地址转换 (translate_address)

将逻辑地址转换为物理地址：

1. **分解逻辑地址**：
   - 页号 = 逻辑地址 / 页面大小
   - 页内偏移 = 逻辑地址 % 页面大小

2. **检查有效位**：
   - 如果页面在内存中（valid = true），直接访问
   - 如果页面不在内存中（valid = false），触发缺页处理

3. **计算物理地址**：
   - 物理地址 = 帧号 × 页面大小 + 页内偏移

4. **更新状态**：
   - 设置访问位（referenced = true）
   - 如果是写操作，设置修改位（modified = true）

### 2. 缺页处理 (handle_page_fault)

当访问的页面不在内存中时：

1. **查找空闲帧**：
   - 如果有空闲帧，直接分配
   - 如果没有空闲帧，执行页面置换

2. **页面置换**（如果需要）：
   - 调用FIFO算法选择被置换的页面
   - 如果被置换页面已修改，写回磁盘
   - 使被置换页面的页表项无效

3. **加载新页面**：
   - 从磁盘加载新页面到选定的帧
   - 更新页表项和帧信息

### 3. FIFO页面置换算法 (fifo_replace)

**基本思想**：选择最早进入内存的页面进行置换

**实现步骤**：
1. 遍历所有物理帧
2. 找到load_time最小的帧
3. 返回该帧号

**优点**：
- 实现简单
- 公平性好

**缺点**：
- 可能置换常用页面
- 不考虑页面使用频率

### 4. 辅助功能

- **find_free_frame**：查找空闲物理帧
- **update_page_table**：更新页表项和帧信息
- **load_from_disk**：模拟从磁盘加载页面
- **save_to_disk**：模拟写回磁盘

## 性能分析

### 缺页率计算
```
缺页率 = (缺页次数 / 总访问次数) × 100%
```

### FIFO算法特性
- **Belady异常**：增加物理帧数可能导致缺页率上升
- **时间复杂度**：O(n)，n为物理帧数
- **空间复杂度**：O(1)，只需维护时间戳

## 注意事项

1. 本实验是模拟系统，磁盘I/O操作是模拟的
2. 页面大小固定为4KB（常见的页面大小）
3. 物理帧数限制为4帧（便于观察置换过程）
4. 时间戳用于FIFO算法，每次访问递增

## 实验要点

### 地址转换过程
```
逻辑地址 = 页号 × 页面大小 + 页内偏移
物理地址 = 帧号 × 页面大小 + 页内偏移
```

### 缺页处理流程
```
1. 检测缺页 → 2. 查找空闲帧 → 3. 页面置换（如果需要）
→ 4. 加载页面 → 5. 更新页表
```

### FIFO算法核心
```
选择load_time最小的页面进行置换
```
