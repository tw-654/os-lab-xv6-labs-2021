# 实验一：动态分区分配算法实现

## 实验概述

本实验实现了三种经典的动态分区分配算法：
- **首次适应算法 (First Fit, FF)**
- **最佳适应算法 (Best Fit, BF)**
- **最坏适应算法 (Worst Fit, WF)**

## 实现说明

### 数据结构

1. **free_area_t**: 空闲分区结构
   - `start_addr`: 起始地址
   - `size`: 分区大小
   - `next`: 指向下一个空闲分区的指针

2. **memory_manager_t**: 内存管理器
   - `free_list`: 空闲分区链表
   - `total_size`: 总内存大小
   - `allocated_count`: 分配次数统计
   - `released_count`: 释放次数统计

### 核心函数

#### 1. 首次适应算法 (First Fit)
- **思想**: 从内存起始地址开始查找第一个能满足要求的空闲分区
- **优点**: 实现简单，分配速度快
- **缺点**: 容易在低地址产生碎片

#### 2. 最佳适应算法 (Best Fit)
- **思想**: 查找能满足要求的最小空闲分区
- **优点**: 减少大分区的浪费
- **缺点**: 容易产生大量小碎片

#### 3. 最坏适应算法 (Worst Fit)
- **思想**: 查找能满足要求的最大空闲分区
- **优点**: 减少小碎片的产生
- **缺点**: 大分区容易被快速消耗

#### 4. 内存释放 (Release Memory)
- 创建新的空闲分区
- 按地址顺序插入到空闲链表
- 合并相邻的空闲分区

## 测试说明

测试程序使用以下测试序列：
```
{50, 30, 20, 40, 60, 10, 25} KB
```

测试流程：
1. 初始化内存管理器（总内存256KB）
2. 依次尝试分配测试序列中的内存块
3. 记录分配成功/失败情况
4. 释放所有已分配的内存
5. 统计并输出结果

## 输出信息

测试程序会输出：
- 每次分配/释放的详细信息
- 内存状态（空闲分区列表）
- 统计信息：
  - 总分配请求数
  - 成功分配数
  - 失败分配数
  - 成功率
  - 内存碎片大小
  - 剩余空闲内存

## 算法性能分析

通过运行测试程序，可以比较三种算法在以下方面的表现：
- **分配成功率**: 在相同测试序列下的成功分配比例
- **内存碎片**: 算法产生的碎片大小
- **内存利用率**: 有效利用的内存比例

## 注意事项

1. 本实现假设内存地址从0开始
2. 内存大小以KB为单位
3. 释放内存时需要提供正确的地址和大小
4. 空闲分区链表按地址升序排列，便于合并
